# NYC Taxi Trip Duration Prediction

Regression project for predicting New York City taxi trip duration.

## Project Goal

Predict taxi trip duration using trip information available at prediction time.

The project uses:

- Ridge Regression
- `alpha = 1`
- `log1p(trip_duration)` as the training target

The main focus is on:

- Data understanding
- Exploratory Data Analysis
- Feature Engineering
- Building a clean ML workflow

## Workflow

1. Data Understanding
2. EDA
3. Feature Engineering
4. Baseline Model
5. Experiments
6. Final Model
7. Refactor notebook code into Python modules
